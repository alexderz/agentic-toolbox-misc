### Qwenx86-4B (compact) — x86 CPU compiled into Qwen3.5-4B weights
@TeksEdge, Nov 6 2026 ~6:05pm CT. https://x.com/TeksEdge/status/2118857211992854892
- **Novel:** Yes — 64-bit x86 computer implemented as compiler-generated transformer layers inside a language-model checkpoint (not a separate emulator process); builds on Qwenputer’s RISC-V-in-weights line.
- **What it is:** Qwen3.5-4B with 13 additional transformer layers ahead of Qwen’s own that implement a 64-bit x86-64 integer core. Card states those chip layers have no learned weights; all values are computed by a compiler (chipformer). The model invokes the computer via its own `<tool_call>` tool calls; firmware baked into the checkpoint answers `calc`, `python` (MicroPython), `c` (qcc small C compiler+runner), `notes_put`/`notes_search`/`notes_get`, `science` (647 CODATA/unit/periodic-table records), and `python_doc` (1,003 Python API signatures). Memory map: 64 KB RAM, 256 KB code ROM, 128 KB read-only data in Gated DeltaNet state. Card tests: 2,000/2,000 x86 instruction lockstep cases vs Unicorn (all registers/flags); selected MSVC-compiled C programs match Unicorn; calc 125/125; science exact recall 647/647; python_doc 1,003/1,003; GSM8K first 28 with calc 26/28 vs 23/28 plain Qwen. Live compact-checkpoint chat timings on a 16 GB card (card table): calc 41.0 s (56,667 machine tokens), python 46.8 s, c 71.2 s. v2 adds host-driven exact memory beside the same weights; v3 lets Qwen issue memory tool calls itself. GGUF/llama.cpp build also published (Windows + NVIDIA CUDA path documented; tested on RTX 5060 Ti 16 GB). Upstream base: Qwenputer (RISC-V, 11 chip layers) by Divyansh Agrawal.
- **License:** Apache-2.0 on the HF card (`license: apache-2.0`). Repo also ships `LICENSE-Qwen3.5` and MIT `chipformer/LICENSE` (from Qwenputer). Base model `Qwen/Qwen3.5-4B`.
- **Size and hardware:** Compact PyTorch checkpoint `model/compact.safetensors` 8,750,014,742 bytes (~8.15 GiB); model/ tree total ~9.02 GB including six boot firmware safetensors (~27.3 MB each) and tokenizer files. Card: ~9 GB GPU memory, fits a 16 GB CUDA GPU. GGUF repo: `gguf/qwenx86-machine-bf16.gguf` 8,700,224,704 bytes + `gguf/qwenx86-text-q4_k_m.gguf` 5,024,347,680 bytes (~13.7 GB together); GGUF README: about 14 GB on one NVIDIA GPU (tested RTX 5060 Ti 16 GB); requires downloading the full repo (not only the two `.gguf` files) plus llama.cpp `b12017` Windows CUDA build and Python 3.12.
