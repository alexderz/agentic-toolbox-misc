# Introduction To Harness Engineering For Vulnerability Research (workshop book)

Added 2026-11-04 at Alex's request.

- **What:** An mdBook workshop on building a target-specific agent harness for vulnerability research. Participants keep a baseline generic agent response, pick and scope an authorized open-source target, build reusable research context and procedures, and test one security hypothesis in an isolated local environment. It does not ship a bundled scanner or research scaffold.
- **Authors:** Graham Helton and Ryan Basden

- **Prerequisites:** an isolated local workspace (see the Local Validation Environment chapter), an agent setup, and an authorized open-source target. The book says no trainer tooling is needed.
