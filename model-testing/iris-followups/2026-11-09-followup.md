Model Master's intake run, 2026-11-11 evening (Central time). Two items.

## OrcaCyber ERNIE 5.5 Flash Base, abliterated (GGUF and MLX)

- **What it is:** OrcaCyber's refusal-removed copy of Baidu's
  [ERNIE-5.5-Flash-Base](https://huggingface.co/baidu/ERNIE-5.5-Flash-Base), a 280B-total / 14B-active MoE
  (10 experts per token). GGUF: [orcarouter/ERNIE-5.5-Flash-Base-abliterated-GGUF](https://huggingface.co/orcarouter/ERNIE-5.5-Flash-Base-abliterated-GGUF).
- **What we checked:** the GGUF repo (revision `4b5c213e`) has three mixes: Mix-60G (59.98 GB), Mix-122G
  (121.99 GB) and Mix-245G (244.61 GB). The repo is **gated**: downloading means accepting OrcaCyber's terms with
  a Hugging Face login, and its README is behind the same gate. The base checkpoint's architecture is `ernie5_5_moe`.
  llama.cpp has no support for it yet: the pull request that adds ERNIE 5.5,
  [ggml-org/llama.cpp#31925](https://github.com/ggml-org/llama.cpp/pull/31925), has been open since Nov 9.
- **Fit:** Mix-122G would fit our "experts in RAM" tier (an RTX 3090 and a V100 with 125 GB of RAM hold about
  160 GB of MoE weights). Mix-60G would load mostly on the two GPUs.
- **Verdict: watch.** Two things block it: no engine we run has the architecture, and the gate needs the owner's
  account. It is also a *base* checkpoint, the end of pretraining with no chat tuning, so removing refusals from it
  changes little. A base model mostly continues text and does not follow instructions. We look again when #31925
  merges.
- **Started:** nothing.

## Stag (change-simulation platform)

- **What it is:** [Stag](https://www.stag.io/), a hosted "change risk prevention" service. It mirrors an
  infrastructure estate (IAM, network, Kubernetes, data) and simulates the blast radius of a change before it ships.
- **Verdict: no value for us.** It is a commercial SaaS for cloud estates with no self-hosted or open part, and a
  house-sized network gains little from it. Nothing to install.
